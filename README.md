# Claude setup bundle for law practices

Free, no opt-in. From the video "I Used Claude for 1,000 Hours. Here's Everything Lawyers Need in 17 Minutes".

**Download:** [setup-bundle.zip](https://github.com/natework000-web/claude-setup-bundle/archive/refs/heads/main.zip)

1. Unzip it and put the `setup-bundle` folder inside the folder you use for your practice.
2. Open Claude Code in that practice folder.
3. Type: **go read the setup-bundle folder and interview me**

Answer the questions (about 10 minutes). Claude writes a `CLAUDE.md` file about your practice (never your clients) and reads it every time you open the folder.
